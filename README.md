# Naval Capability Tracker

Quantitative time series on Mediterranean naval activity, derived from open
satellite data. The asset is the longitudinal archive, not the tooling.

## Method

Activity is measured, not identified. Metrics are dock occupancy, hull counts
above a size threshold, and approximate hull-length distributions, computed
server-side from Sentinel-1 SAR. Vessel classification is not attempted from
imagery.

Status: early development.
